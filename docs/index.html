MCP bridge for Roblox Studio

Connect Arena AI to Roblox Studio.

Mint is an open-source MCP app that lets AI clients inspect your open place, edit scripts, create instances, and run Luau commands inside Roblox Studio — through a local, secure bridge you control.

What it can do

Built for real Studio workflows.

Mint exposes Roblox Studio actions as MCP tools, so your AI client can work with the place you already have open.

Explore the DataModel

List children, inspect properties, find instances, and read the current selection in your open Roblox place.

Edit scripts

Read and write Script, LocalScript, and ModuleScript source with Studio-aware updates and undo history.

Create and modify instances

Create new instances, set properties, and delete objects — all through explicit MCP tool calls.

Run Luau commands

Execute Luau in Studio for quick inspections, bulk changes, or prototyping when a dedicated tool isn't enough.

Local-first bridge

The bridge runs on your machine. Your MCP client talks to the local server; the Studio plugin polls locally.

Works with MCP clients

Designed for Arena AI and compatible with other MCP clients that support local stdio servers.

How it works

A simple local bridge.

Roblox Studio plugins can make outbound HTTP requests. Mint uses that to create a safe local command loop.

1

Arena AI / MCP client

Your AI client calls an MCP tool like roblox_set_script_source.

2

Mint MCP server

The local Node.js server receives the tool call and places a command on the bridge.

3

Roblox Studio plugin

The Mint plugin polls 127.0.0.1:5123, runs the command, and returns the result.

Setup

Up and running in minutes.

No executable installer yet — download the source, install dependencies, and connect your MCP client.

1

Download Mint

Clone the repository or download the source ZIP from GitHub.

git clone https://github.com/livinginanicebox/Mint.git
cd Mint
2

Install and build

Requires Node.js 18+. Install dependencies and compile the TypeScript server.

npm install
npm run build
3

Install the Roblox Studio plugin

Copy plugin/MintMCPPlugin.rbxmx into your Roblox Studio plugins folder, then restart Studio or enable the plugin. Click the Mint MCP toolbar button to connect.

4

Add Mint to your MCP client

Point your MCP client at the built server. For Arena AI or any stdio MCP client, use a config like this:

{
  "mcpServers": {
    "mint-roblox": {
      "command": "node",
      "args": ["C:/path/to/Mint/dist/index.js"]
    }
  }
}

Use the absolute path to dist/index.js on your machine. After connecting, call roblox_bridge_status to confirm Studio is linked.

Available MCP tools

  • roblox_bridge_statusCheck bridge/plugin connection
  • roblox_get_selectionRead current Studio selection
  • roblox_list_childrenBrowse instance children
  • roblox_get_propertiesInspect instance properties
  • roblox_set_propertySet a property value
  • roblox_create_instanceCreate a new instance
  • roblox_delete_instanceDelete an instance
  • roblox_get_script_sourceRead script source
  • roblox_set_script_sourceUpdate script source
  • roblox_run_codeRun Luau in Studio
  • roblox_find_instancesSearch by class/name

Security note

Mint is a local development tool. It can read and modify your open Roblox Studio place through the commands your MCP client sends. Only connect MCP clients you trust, and review actions before allowing them in sensitive places.
